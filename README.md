# ISL AI Translator 🇮🇳

An AI-powered Indian Sign Language recognition system using:

- Python
- OpenCV
- MediaPipe
- Machine Learning
- Real-time gesture recognition

## Features
- Real-time webcam prediction
- ISL gesture recognition
- AI HUD interface
- Multi-hand support
- Custom gesture training

## Tech Stack
- Python
- OpenCV
- MediaPipe
- scikit-learn
- NumPy
